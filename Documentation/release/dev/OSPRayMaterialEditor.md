# OSPRay Material Editor

If you use OSPRay to render materials in ParaView (enabled with the PARAVIEW_ENABLE_RAYTRACING cmake option), you have now a specific widget to control the OSPRay materials by enabling it under the "View... Material Editor" menu.

This editor allows you to :

* Load a material library using a .json file or create materials directly in the GUI
* Edit / Add / Remove properties on the materials
* Attach the selected material to the current selected source
