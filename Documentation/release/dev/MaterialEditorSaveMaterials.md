# New feature: Save OSPRay materials in the material editor

You can now save the materials created in the material editor (enabled with PARAVIEW_ENABLE_RAYTRACING and VTK_ENABLE_OSPRAY) using the 'Save materials' button.

It will write all materials in a new file in a json format (see https://gitlab.kitware.com/paraview/materials/blob/master/ospray_mats.json for an example)
